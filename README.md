# Tatar OCR («Кара куян»)

Автономная система компьютерного зрения и OCR для автоматической проверки рукописных учебных бланков по татарскому языку.

Проект решает задачу верификации ответов в печатных сетках бланков: фото листа преобразуется в каноническую систему координат, сегментируется на ячейки и распознается локальной нейросетью полностью **офлайн** прямо на устройстве.

---

## Цели проекта

1. **Офлайн-проверка на устройстве:** Полная независимость от интернета и облачных сервисов (защита персональных данных учащихся, соответствие 152-ФЗ).
2. **Точность на детском и рукописном почерке:** Посимвольное распознавание 39 заглавных букв татарского кириллического алфавита, включая 6 специфических символов (**Ә, Ө, Ү, Җ, Ң, Һ**) и диакритические знаки (**Ё, Й**).
3. **Человек в контуре (Human-in-the-Loop):** Посимвольная оценка уверенности, флаги сомнительных ответов и вывод Top-3 вероятных кандидатов для быстрой верификации учителем.
4. **Кроссплатформенное ядро без дублирования:** Единое C++20 ядро компьютерного зрения и инференса, одинаково работающее в Python-окружении и нативно в мобильном приложении на Android.

---

## Технологический стек

* **Языки:** C++20 (основное ядро), Python 3.12 (фасад, исследования, обучение).
* **Компьютерное зрение:** OpenCV (C++ / Python), маркеры ArUco (`DICT_4X4_50`) для выравнивания перспективы.
* **ML & Инференс:** 
  * **PyTorch** — разработка архитектуры, аугментации и многоэтапное обучение;
  * **ONNX Runtime** (C++ API / Python API) — высокоскоростной батчевый инференс квантованной модели.
* **Связка и сборка:** CMake, `pybind11`, `nlohmann/json`.
* **Архитектурный стандарт:** Декларативная JSON-спецификация (`pipeline_spec.json`) как единый источник правды (Single Source of Truth).

---

## Текущая реализация

### 1. Декларативная спецификация (`pipeline_spec.json`)
Все параметры бланка и конвейера вынесены в декларативный конфиг:
* Канонический размер листа (A4: 2100×2970) и координаты 4-х ArUco-маркеров.
* Сетка ответов (11 строк, 13 колонок ячеек) и геометрические отступы.
* Параметры CV-фильтрации (подавление границ ячеек, центрирование чернил, проверка пустоты, эвристики диакритики).
* Алфавит (39 символов) и целевая модель.

### 2. Нейросетевая модель v4 INT8 (`models/tatar_ocr_v4_handwritten39_int8.onnx`)
* **Архитектура:** `MultiScaleHandwrittenCNN` — параллельные сверточные ветки (ядра 3×3, 5×5, 7×7) с механизмами внимания Squeeze-and-Excitation (SE-блоки) для точного улавливания тонких штрихов и диакритики.
* **Квантование:** Модель квантована в **INT8**, вес составляет всего **~1.0 МБ** (входной тензор $64 \times 64$, 39 классов).
* **Качество на бенчмарке из 12 реальных бланков:**
  * Посимвольная точность (**Acc_char**): **96.88%** (435/449).
  * Ошибки на символ (**CER**): **3.12%**.
  * Распознавание специфических татарских букв (**R_Tatar**): **97.33%** (Ә, Ү, Җ, Ң — 100%, Ө — 95.2%, Һ — 83.3%).
  * Точное совпадение полей (**FEM**): **78.95%** (с допуском $\le 1$ ошибки — **96.49%**).

### 3. Нативное C++20 ядро (`native/`)
Высокопроизводительная переносимая библиотека `tatar_ocr_core` и модуль `tatar_ocr_native`:
* **Выравнивание:** Детекция маркеров ArUco, расчет матрицы гомографии и устранение искажений перспективы (`warpPerspective`).
* **Сегментация:** Привязка углов таблицы (corner snapping), очистка контуров ячейки (border suppression) и центрирование символа.
* **Батчевый инференс:** Все заполненные ячейки листа группируются в единый тензор `(N, 1, 64, 64)` и прогоняются через ONNX Runtime за один вызов.
* **Результат:** Формирование структуры с распознанным текстом, флагами пустоты, уверенностью и Top-3 кандидатами.

### 4. Фасад и инструменты разработки
* **`blank_pipeline.py`:** Тонкий фасад над C++ ядром (всего ~360 строк) с сохранением обратной совместимости для тестов и PyTorch `.pth` моделей.
* **`pipeline_debug.py`:** Вынесенные инструменты отладки (отрисовка разметки, бейджей уверенности, инспекция ячеек).
* **`visualize_pipeline.py`:** Интерактивный веб-интерфейс (`http://127.0.0.1:8080`) с поддержкой drag-and-drop бланков и инспекцией Top-3 кандидатов по каждой ячейке.

## Быстрый старт

### Сборка нативного ядра (C++)
Требуются CMake $\ge$ 3.20, компилятор с поддержкой C++20, OpenCV и ONNX Runtime:

```powershell
cd native
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release
```

### Запуск веб-визуализатора
```powershell
python visualize_pipeline.py --serve --port 8080
```
Интерфейс доступен в браузере по адресу `http://127.0.0.1:8080`.

### Оценка качества на бенчмарке
```powershell
python v3/evaluate_blanks.py --onnx models/tatar_ocr_v4_handwritten39_int8.onnx
```

## Интеграция в Android
Для сборки под Android C++20 ядро подключается как CMake-подпроект в Android NDK (`externalNativeBuild`):
1. **Ядро:** `native/src/tatar_ocr.cpp` компилируется под `arm64-v8a` с подключением Android NDK, OpenCV Android SDK и `onnxruntime-android`.
2. **Конфигурация:** `pipeline_spec.json` и файл модели `tatar_ocr_v4_handwritten39_int8.onnx` помещаются в `assets/`.
3. **JNI:** Простой JNI-мост передает bitmap/путь к фото и возвращает структурированный результат проверки в Kotlin.
