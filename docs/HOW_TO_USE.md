# Шпаргалка для человека (запоминать не нужно)

Агент сам читает `AGENTS.md` и `GEMINI.md` при каждом запуске и ведёт процесс сам. Достаточно писать обычным языком:

- **Починить мелкий баг:** *«В файле X падает Y — почини и прогони тест».*
- **Сделать фичу / изменить API / C++ / модель:** *«Хочу добавить фичу X»* $\rightarrow$ агент сам создаст задачу в `harness/changes/active/`, покажет короткий план и спросит «Стартуем?».
- **Продолжить после паузы или в новом чате:** *«Продолжай текущую задачу»* $\rightarrow$ агент сам прочитает `docs/STATUS.md` и `tasks.md`.
- **Завершить задачу:** когда агент покажет, что всё проверено и ревью пройдено, просто ответьте *«Закрывай»* — он сам обновит документацию и уберёт задачу в архив.
- **Переключиться на срочное:** *«Отложи текущую, сначала срочно сделай Y»* $\rightarrow$ агент сам припаркует задачу в `parking/`.
